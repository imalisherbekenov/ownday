# Ownday

Трекер привычек на четырёх поверхностях: Telegram-бот, веб, Telegram Mini App и
мобильное приложение с виджетами на домашнем экране. Одно ядро, одна дизайн-система,
одна база.

## Команды

| Команда | Что делает |
|---------|------------|
| `pnpm install` | Установить зависимости |
| `pnpm --filter @ownday/bot dev` | Запустить бота локально (long polling) |
| `pnpm --filter @ownday/web dev` | Запустить веб на порту 3111 |
| `pnpm test` | Прогнать тесты |
| `pnpm typecheck` | Проверить типы |
| `pnpm build` | Собрать всё |
| `pnpm format:check` | Проверить форматирование |
| `npx turbo run test --force` | Тесты в обход кэша Turbo |

## Структура

- `packages/core` — доменная логика без I/O: границы дня, расписания, серии
- `packages/db` — Prisma-схема и клиент
- `packages/services` — прикладной слой над базой
- `packages/tokens` — дизайн-токены, генерируются из `docs/design.md`
- `packages/ui` — общие компоненты
- `apps/bot` — Telegram-бот на grammY
- `apps/web` — Next.js: веб и Mini App
- `apps/mobile` — Expo с нативными виджетами

## Правила

- Единственный источник токенов — `docs/design.md`. Литеральных хексов в коде нет.
- `packages/core` не знает ни про базу, ни про сеть — логика серий одинакова на всех
  четырёх поверхностях именно поэтому.
- Кэш Turbo умеет показывать зелёные ворота на непроверенном коде — при приёмке
  гонять с `--force`.

## Как здесь работает Autopilot

Сборка ведётся навыком `/autopilot`. Требования, спецификация и таски — в `.autopilot/`.
Прогресс — `.autopilot/dashboard.html`. Правило: требование из `manifest.md`
может снять только пользователь.

Если работа продолжается — скажи «продолжи автопилот»: состояние поднимется
из `.autopilot/state.js`, переспрашивать ничего не нужно.
