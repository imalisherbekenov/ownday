> **Заглушка не ставит `data-mini-app`.** Атрибут выставляет только инлайновый скрипт в
> `<head>`, а он исполняется раньше, чем появляется заглушка. Значит правило
> `:root[data-mini-app="true"] .app-header` под `?mockTelegram=1` не срабатывает, и §10
> заглушкой не проверить. **Первым делом почини это**, иначе у тебя нет способа принять
> собственную работу: под заглушкой атрибут должен стоять так же, как в настоящем Telegram.
>
> **По D02:** места вызова `useTelegram()` в этих трёх файлах уже приведены к новому

> MainButton, haptic) по-прежнему целиком твоё.

## Что должно заработать

Внутри Telegram по приложению можно ходить. Внизу — навигация, сверху — телеграмовский
заголовок вместо нашего, «назад» работает родной кнопкой Telegram и не выкидывает из
приложения. Форма подтверждается большой кнопкой внизу экрана, которую рисует сам
Telegram. Отметка привычки отзывается лёгкой вибрацией.

Сейчас внутри Telegram оболочка возвращает `<>{children}</>` — ни навигации, ни отступов.
Перемещаться между экранами физически невозможно.

## Критерии приёмки

**Оболочка**

- [ ] `AppShell` разделён на `WebShell` (нынешний код целиком, без изменений поведения)
      и `MiniAppShell`; выбор — по `webApp !== null` из `useTelegram()`
- [ ] `MiniAppShell`: нижняя навигация есть, сайдбара нет, своего хедера нет
- [ ] Класс `app-header` стоит на **всех восьми** экранах, а не на двух
      (сейчас только `page.tsx` и `habit/[id]/page.tsx`). Правило
      `:root[data-mini-app="true"] .app-header` в `globals.css` уже написано
- [ ] Отступ снизу учитывает `env(safe-area-inset-bottom)` и нижнюю навигацию Telegram

**BackButton**

- [ ] Показан на вложенных маршрутах: `/habits/new`, `/habits/[id]/edit`, `/habit/[id]`,
      `/templates`. Скрыт на корневых
- [ ] **При `history.length <= 1` уводит на `/`, а не вызывает `back()`** — вход по
      дип-линку даёт пустую историю, и `back()` там закрывает Mini App
- [ ] Отписывается при уходе с экрана

**MainButton**

- [ ] `PrimaryActionAdapter` применён на всех экранах с формой: создание привычки,
      редактирование, настройки
- [ ] В `useEffect` есть путь очистки — `offClick` и `hide`. Без него кнопка предыдущего
      экрана остаётся висеть и подтверждает не ту форму
- [ ] Владелец MainButton — только адаптер. Двух компонентов, вешающих обработчик на одну
      кнопку, быть не должно

**Haptic**

- [ ] Лёгкая вибрация (`impactOccurred("light")`) на отметке привычки — и только на ней
- [ ] Вызов идёт через провайдер с проверкой наличия: `HapticFeedback` отсутствует в
      старых клиентах и целиком отсутствует вне Telegram. Обращение без проверки роняет
      экран
- [ ] Вне Telegram — тишина и ни одной ошибки в консоли

**Прочее**

- [ ] `disableVerticalSwipes()` при версии клиента ≥ 7.7 — иначе прокрутка списка
      закрывает окно на Android. При меньшей версии — молча пропустить
- [ ] Обычный веб не изменился ни на пиксель: 12 существующих тестов зелёные,
      сайдбар и нижняя навигация на месте
- [ ] Проверено вручную через `?mockTelegram=1`: переход по всем четырём разделам,
      BackButton с вложенного экрана, BackButton при пустой истории, MainButton на форме
- [ ] `npx turbo run test typecheck build format:check --force` зелёный
