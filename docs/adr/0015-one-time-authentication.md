# 0015 — Одноразовый вход и отзываемые сессии

Статус: серверная реализация и проверки PostgreSQL готовы; подключение аккаунта к синхронизации мобильного интерфейса продолжается.

Мобильное приложение хранит случайный PKCE verifier в SecureStore. В браузер передаётся только SHA-256 challenge и случайный state. После входа сервер возвращает на единственный фиксированный адрес `ownday://auth/callback` код со сроком 60 секунд. Приложение проверяет state и обменивает код вместе с verifier по HTTPS. Долгоживущего токена в URL нет.

Получение кода и создание сессии выполняются в транзакции: из нескольких одновременных попыток проходит одна. Если ответ на обмен потерян, требуется новый вход; локальные привычки и история остаются на устройстве.

Срок мобильной сессии — 30 дней, браузерной — 7 дней с продлением при активности. В базе находятся SHA-256 хеши случайных токенов. Выход отзывает сессию. Старые подписанные браузерные cookies принимаются до их исходного истечения и при активности заменяются новым форматом. Старые мобильные bearer JWT требуют повторного входа. Идентификаторы пользователей и история не меняются.

Ссылки из писем также одноразовые, срок — 10 минут, назначение проверяется при атомарном получении. Старые JWT-ссылки из писем больше не принимаются; пользователь может запросить новую.

Для входа требуется PostgreSQL. Память процесса не используется как хранилище одноразовых кодов. Локальные тесты браузерных cookies сохраняют явный тестовый JWT-адаптер без подключения к БД. Middleware работает в Node.js, чтобы проверять и продлевать отзываемые сессии.

Проверено на PostgreSQL с часовым поясом сервера Asia/Tashkent: восемь одновременных обменов, неверный verifier, истечение, отзыв и однократное использование письма. SQL сравнивает даты в UTC, как хранит их Prisma.
