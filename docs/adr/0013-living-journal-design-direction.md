# 0013. Визуальное направление «Живой дневник»

Статус: принято пользователем 13 сентября 2026 года.

## Решение

Пользователь выбрал вариант C — «Живой дневник» из трёх интерактивных демо
`apps/design-lab`. Он становится визуальным направлением мобильного приложения,
публичного сайта, веб-приложения и Telegram Mini App.

Сохраняем тёплые поверхности, выразительную типографику, мягкие цветовые блоки,
небольшие ботанические иллюстрации и организацию дня по утру, дню и вечеру.
Интерфейс поддерживает личный ритм без давления из-за пропусков.

## Последствия

- В новых сессиях стенда по умолчанию открывается C. A/B остаются для сравнения.
- Существующие привычки и сохранённые предпочтения демо не сбрасываются.
- Промышленные компоненты получают это оформление через общие токены и
  платформенные реализации. Монолитный React-прототип не переносится в Native.
- Выбор композиции не утверждает каждое расстояние, цвет или шрифт прототипа:
  при переносе обязательны контраст, масштабирование текста и проверка устройств.
- `docs/design.md` пока описывает действующие токены. Их изменение выполняется
  вместе с компонентами; этот ADR фиксирует целевое направление.
- Архитектура данных и конфликтов синхронизации не определяется внешним видом.

Спецификация следующих этапов: [Ownday — реализация](../ownday-implementation.md).
